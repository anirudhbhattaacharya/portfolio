Tcl I actually wrote

ECO displacement report

Small ECO on ORCA. Added cells and nets, set eco_change_status = create_cell so place_eco_cells -eco_changed_cells would see them, captured locations before and after, wrote a CSV with previous xy, current xy, delta and displacement.

Cells outside core boundary

Report cells and macros outside the core. Used the boundary attribute instead of bbox so rectilinear cores work. Point-in-polygon with ray casting. Checked four corners plus center. Fallback to origin for unplaced cells.

Command-trace extraction

The Qualcomm GSAE piece. sh_command_log_file for top-level commands, log_trace for the expanded history, logsum.html as a browser view. File checks in run.tcl so the testcase does not die halfway.
